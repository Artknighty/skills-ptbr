# Misc

Ferramentas mantidas, mas raramente usadas, não incluídas no plugin.

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**: Configura hooks do Claude Code para bloquear comandos git perigosos (push, reset --hard, clean etc.) antes que sejam executados.
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**: Migra arquivos de teste de type assertions com `as` para @total-typescript/shoehorn.
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**: Cria estruturas de diretório de exercícios com seções, problems, solutions e explainers.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**: Configura hooks de pre-commit com Husky, lint-staged, Prettier, typecheck e testes.
